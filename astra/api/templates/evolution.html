Autonomous evolution loop

Runs walk-forward generations: each one replays the NEXT, never-traded window of history starting from $10k. The bot carries its per-stock strategy knowledge (profiles + policy model) forward, but never the price path — every window is a fresh, unseen time period, so each generation is an honest out-of-sample test. Between generations a bounded tuner nudges the risk knobs; the next unseen window validates the change automatically. The loop stops when the return target is hit, the windows run out, or performance plateaus.
